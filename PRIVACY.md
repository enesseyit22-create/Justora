# Privacy Policy

Justora stores your tasks, timers, moods, streaks, and settings on this device. There is no account. Justora does not treat, diagnose, or collect a health record.

Notifications are scheduled on the device. If you buy Pro, Apple or Google Play, and RevenueCat, receive an anonymous app user id and the purchase receipt so the subscription can be verified. Justora does not ask for your name or email for that.

If you install a release build with Expo Update configured, the app may request a JavaScript update. That request includes the project id, platform, and runtime version. Your task list is not uploaded.

The in-app policy is localized. This file is the English source to host before submission. The contact address is enesmeryem5@gmail.com.
